# SEMANA 1 - ONBOARDING

Bienvenido al repositorio de documentación correspondiente a las actividades y aprendizajes de la **Semana 1 de Onboarding**. 


##  Índice de Documentación

A continuación se detallan los temas cubiertos durante la semana. Cada enlace dirige a la bitácora específica del tema:

*  AI Responsable - (AI-RESPONSABLE.md) — Principios, beneficios y aplicaciones de IA Responsable en Azure.
*  Azure Portal - (AZURE-PORTAL.md) — Gestión, navegación y administración de recursos en Microsoft Azure.
*  Cloud Studio - (CLOUD-STUDIO.md) — Entorno de desarrollo y herramientas en la nube.
*  Git y GitHub - (Git-GitHub.md) — Control de versiones, flujo de trabajo por ramas (Git Flow) y Pull Requests.
*  Herramientas - (HERRAMIENTAS.md) — Descripción y uso de las herramientas principales de trabajo.
*  Seguridad en Cloud - (SEGURIDAD EN CLOUD.md) — Fundamentos y buenas prácticas de seguridad en la nube.
*  VS Code e IaC - (Vs-Code.md) — Configuración de entorno de desarrollo e Infraestructura como Código.


##  Flujo de Trabajo y Metodología
Este repositorio fue estructurado siguiendo las mejores prácticas de
- Desarrollo en ramas independientes **feature branches** por cada módulo.
- Integración continua mediante **Pull Requests** revisados y fusionados a la rama principal **main**.
- Mantenimiento y limpieza del repositorio mediante la eliminación de ramas secundarias tras el **merge**.
